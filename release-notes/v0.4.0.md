## New
- Tap any relay to see its details: name and description, response time, cost, sign-in rules, features, limits, contact and any recent problems
- The relay list now shows a status dot and response time for each relay, plus a tag such as "Paid" when that applies
- Relays are now organized by type: General, Messaging, Search and Profile lookup, and you can edit each one

## Improved
- New accounts start with free relays for each type, chosen after testing that they work today

## Fixed
- Search no longer relies on a relay that stopped responding, unless you've set your own search list
- Finding people's relays no longer relies on a lookup relay that wasn't returning results
