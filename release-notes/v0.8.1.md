## Fixed
- **Back gestures piling up in threads:** tapping comments in a thread opened the same thread again each time, so leaving took one back gesture per tap. Now tapping a comment picks it to reply to, and one back gesture leaves
- **Going in circles:** opening a screen that's already open, like a profile from its own notes, a hashtag from the same hashtag, or a chat from its person's profile, now goes back to it instead of stacking another copy
