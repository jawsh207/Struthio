## Improved
- Posts, comments and private messages finish much sooner: Struthio moves on as soon as the first relay accepts, and the rest catch up in the background
- Reactions and boosts now show the moment you tap, and undo themselves if sending fails
- Tagging someone no longer slows down your post

## Fixed
- A post that no relay accepted no longer appears as if it had been sent
- Leaving a screen can no longer interrupt something you've already signed
